# Lock Top Bar (Блокировка топбара)

Плагин для панели статуса [Omarchy](https://omarchy.org) (`omarchy-shell` / Quickshell), добавляющий иконку «замочка» на топбар.

При активной блокировке плагин защищает топбар от нежелательных случайных кликов:
- **Блокирует смену прозрачности**: предотвращает переключение фона бара (`opaque` / `glassy` / `none`) при случайном двойном клике по бару.
- **Блокирует смену раскладки столов**: предотвращает переключение режима активного рабочего стола (dwindle / scrolling / floating) при клике на номер активного стола на панели.
- **Блокирует перетаскивание бара**: защищает от случайного сдвига панели на другой край экрана.
- **Уведомления**: показывает аккуратное всплывающее сообщение при попытке заблокированного действия.
- **Поддержка IPC**: переключение и статус через командную строку и горячие клавиши Hyprland.

> ID в каталоге плагинов: `io.github.culcat.lock-topbar`

## Возможности

- **Иконка на топбаре**:
  - `󰌾` **Заблокирован** (акцентный цвет) — защита топбара включена.
  - `󰌿` **Разблокирован** (приглушённый цвет) — стандартное поведение бара.
- **Левый клик**: Быстрое включение / выключение блокировки.
- **Правый клик**: Открытие карточки настроек:
  - *Блокировать фон бара* (запрет смены прозрачности)
  - *Блокировать режим столов* (запрет смены раскладки активного стола)
  - *Уведомления* (оповещать при блокировке действия)
- **Сохранение состояния**: Запоминает статус блокировки и настройки между перезапусками оболочки.
- **Локализация**: Полная поддержка русского и английского языков.

## Установка

Установка через менеджер плагинов Omarchy:

```bash
omarchy plugin add https://github.com/culcat/LockTopBar.git --enable
```

Перемещение виджета (например, в правую секцию):

```bash
omarchy bar move io.github.culcat.lock-topbar --section right
```

### Удаление

```bash
omarchy plugin disable io.github.culcat.lock-topbar
omarchy plugin remove io.github.culcat.lock-topbar
```

## Горячие клавиши и IPC

Вы можете назначить переключение на горячую клавишу в `~/.config/hypr/bindings.lua`:

```lua
-- Переключение блокировки топбара по Super + Alt + L
hl.bind({ "super", "alt" }, "l", "omarchy-shell io.github.culcat.lock-topbar toggle")
```

Команды IPC:
```bash
omarchy-shell io.github.culcat.lock-topbar toggle
omarchy-shell io.github.culcat.lock-topbar lock
omarchy-shell io.github.culcat.lock-topbar unlock
omarchy-shell io.github.culcat.lock-topbar status
```
